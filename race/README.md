# NITRO RUSH — уличные гонки

Аркадные гонки в духе Asphalt для телефона: заезды по ночным улицам, дрифт,
нитро, карьера из 5 серий, гараж с 12 машинами и тюнингом. Игра полностью
офлайн, весь контент — свой (машины, трассы, музыка). Работает в браузере и
как APK на Android.

<p align="center"><b>Как запустить</b></p>

## 1. На телефоне без установки (быстрее всего)

1. Скачайте файл `dist/NITRO RUSH.html` (одним файлом ~900 КБ, внутри всё:
   движок, музыка, графика).
2. Перекиньте его на телефон (Telegram «Избранное», кабель, Google Drive — как удобно).
3. Откройте файл в Chrome → «Добавить на главный экран», если хочется иконку.
4. Играйте. Интернет не нужен вообще.

## 2. APK (обычное приложение Android)

APK собирается автоматически:

* GitHub → вкладка **Actions** → workflow **Build NITRO RUSH APK** → **Run workflow**;
* после сборки скачайте артефакт `nitro-rush-apk` (внутри `app-debug.apk` и
  `app-release.apk`) и установите на телефон.

> Если Actions отключены, включите их: **Settings → Actions → General →
> Allow all actions**. Для установки APK телефон попросит разрешить установку
> из неизвестных источников.

Сборка вручную (нужны JDK 17 и Android SDK 34):

```bash
node tools/build-offline.js --android   # положить игру в assets
cd android && gradle assembleDebug      # APK: app/build/outputs/apk/debug/
```

## 3. В браузере на компьютере

Откройте `race/index.html` (любой статический сервер, например
`python3 -m http.server`). Управление — стрелки/WASD, `Shift` — нитро,
`Space` — ручник, `Esc` — пауза.

---

## Управление на телефоне

| Элемент | Действие |
|---|---|
| Кнопки `‹` / `›` или наклон телефона, или свайп | поворот (переключается в настройках) |
| Газ | автоматический (можно отключить в настройках) |
| Тормоз/назад | торможение и задний ход |
| Дрифт (ручник) | заносит заднюю ось — держите в повороте для дрифта |
| Нитро | ускорение; заряжается за дрифт, прыжки и чистую езду |

Советы: тормозите **до** поворота, в повороте держите дрифт и отпускайте газ —
тогда копится нитро; на трамплинах не отпускайте газ — прыжок даёт бонус.

## Что есть в игре

* **6 трасс** со своей атмосферой: Неоновый город, Прибрежное шоссе, Горный
  серпантин, Пустынная трасса, Промзона, Альпийский перевал (лёд, ночь, дождь
  не нужен — снег и лёд уже там).
* **12 машин** классов D → S: от учебного «Вихря» (205 км/ч) до «Феникса GT»
  (388 км/ч). Паспортные 0–100 и максимальная скорость совпадают с тем, что
  машина реально показывает на трассе (модель разгона откалибрована под цифры).
* **Тюнинг**: двигатель, коробка, шины, нитро — по 5 уровней на каждую.
* **Карьера**: 5 серий × 4 события. Режимы: гонка, дуэль, заезд на время,
  погоня с полицией (не дайте разбить машину). Звёзды открывают следующие серии.
* **Дрифт-система**: занос заряжает нитро и приносит кредиты.
* **Трамплины**, прыжки, столкновения, повреждения, скользкие участки.
* **Гараж**: покупка машин, апгрейды, 10 цветов кузова и акценты.
* **Прогресс сохраняется** (localStorage / в APK — та же механика).

## Технически

* Собственный аркадный движок: two-axle slip-модель физики (сцепление, заносы,
  перенос веса, трамвайный круг тяги, ручник), фиксированный шаг 1/90 с.
* Трассы генерируются процедурно из контрольных точек: полотно, бордюры,
  разметка, барьеры, ландшафт (рельеф повторяет высоты трассы), пропсы и
  трамплины — всё из кода, без внешних ассетов.
* Рендер: three.js r160 (встроен в `src/three.min.js`), инстансинг пропсов,
  градиентное небо шейдером, туман, ~50 000 треугольников на трассу.
* Адаптивное качество: определяется GPU/ядра, затем по фактическому FPS
  подстраивается разрешение рендера (диапазон 0.6–1.0).
* Звук: WebAudio, всё синтезируется на лету — двигатель, визг шин, удары,
  нитро и музыкальный луп (без аудиофайлов).

### Структура

```
race/
  index.html          экран игры (HUD, меню, стили)
  src/util.js         математика, RNG, форматирование
  src/cars.js         каталог машин, генерация кузова, расчёт характеристик
  src/tracks.js       генератор трасс + валидация геометрии
  src/physics.js      физика машины, сцепление, столкновения
  src/race.js         гонка, ИИ соперников, карьера, награды, сохранения
  src/scene.js        мир: дорога, ландшафт, небо, пропсы, эффекты
  src/audio.js        процедурный звук
  src/hud.js          камера, HUD, миникарта
  src/app.js          экраны, ввод, игровой цикл
```

### Тесты

```bash
node tools/test-sim.js      # физика, ИИ, геометрия трасс, карьера, экономика  (162 проверки)
node tools/test-scene.js    # целостность сцен, машины, эффекты                 (85 проверок)
node tools/test-ui.js       # прогон приложения в jsdom + проверка сборки      (73 проверки)
node tools/build-offline.js # собрать dist/NITRO RUSH.html
```

Тесты гоняют полные заезды ИИ на всех трассах, проверяют, что машины
проходят круг, не проезжают сквозь стены, что разгон совпадает с паспортным,
что награды и экономика сходятся, а приложение поднимается из меню до
результатов гонки.
