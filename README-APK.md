# Minecraft Classic — приложение для Android (APK)

Игра целиком лежит в одном файле `minecraft/Minecraft.html` (≈1,4 МБ) и
работает офлайн. Этот каталог — обёртка, превращающая её в обычное приложение
Android: иконка в меню, полный экран, сохранение прогресса, кнопка «Назад»
закрывает инвентарь и торговлю.

---

## Почему телефон предупреждает при установке

Сразу важное: **предупреждение выдаёт сам Android, а не игра**. Внутри APK
нельзя «встроить антивирус», который повлияет на этот текст — телефон решает
сам, доверять ли приложению, и смотрит не на его содержимое, а на два факта:
подписано ли приложение ключом Google и скачано ли оно из Play Store. Любой APK
со стороны (sideload) система помечает как «неизвестный источник». Это не
признак вируса, это политика Android.

Что реально убирает предупреждения:

| Способ | Предупреждения | Комментарий |
|---|---|---|
| «Всё равно установить» в окне Play Protect | один раз, при установке | самый быстрый путь, см. ниже |
| Установка через ПК: `adb install app-release.apk` | нет совсем | без диалогов, нужен кабель и adb |
| Публикация в магазине (RuStore, Google Play, Amazon) | нет совсем | единственный способ убрать их навсегда |
| Временно выключить «Сканировать приложения» в Play Store → Play Protect | нет | так вы ослабляете защиту для **всех** приложений — не рекомендую как постоянное решение |

Если Play Protect пишет именно «приложение может быть вредоносным» (а не просто
«неизвестный источник») — это уже конкретная метка Google, и её можно обжаловать
через форму Play Protect appeal (support.google.com/googleplay/android-developer).

### Как поставить на телефон по шагам

1. Скачайте `app-release.apk` из релиза.
2. Откройте файл на телефоне.
3. Android спросит разрешение ставить приложения из этого источника (браузер или
   файловый менеджер) — разрешите. Вопрос разовый.
4. Если появится окно Play Protect «Небезопасное приложение заблокировано»:
   **«Подробнее» → «Всё равно установить»**.
5. Запустите «Minecraft Classic».

Проверить файл, если остаются сомнения:

* сравните SHA-256 с файлом `SHA256SUMS.txt` из релиза;
* можно загрузить APK на virustotal.com — там будет видно, что детектов нет.

### Что сделано в проекте, чтобы приложение выглядело (и было) чистым

* **Разрешения INTERNET нет.** Оно не просто не запрашивается: в манифесте стоит
  `<uses-permission android:name="android.permission.INTERNET" tools:node="remove" />`,
  то есть даже подключённая позже библиотека не сможет его добавить. Приложению
  физически некуда передавать данные.
* **Нет JS-моста** (`addJavascriptInterface`), нет загрузки внешнего кода
  (`DexClassLoader`), нет загрузки страниц из интернета и нет доступа WebView к
  локальным файлам — это самые частые причины ложных срабатываний сканеров.
* **Release-сборка не отладочная**, сжатие кода выключено (открытый, читаемый
  код — тоже плюс к доверию).
* **Постоянная подпись.** `android/hobby-signing-key.p12` — публичный ключ этого
  проекта (пароль `minecraft`). Он не секрет и ничего не защищает; он нужен,
  чтобы новые версии ставились **поверх** старых. Иначе Android сказал бы
  «Приложение не установлено», и пришлось бы удалять игру вместе с прогрессом.
  Если проект пойдёт в магазин — там нужен приватный ключ в секретах CI.
* **CI проверяет всё это на каждой сборке:** распаковывает готовый APK,
  сравнивает игру внутри с исходником байт в байт и падает с ошибкой, если в
  итоговом манифесте появится INTERNET или флаг отладочной сборки.
* **Исходный код открыт** — любой может прочитать, что делает приложение
  (файл `android/app/src/main/java/com/mcclassic/game/MainActivity.java`,
  около 250 строк).

### Про название

Приложение называется «Minecraft Classic» и использует узнаваемую иконку-кубик.
Изредка сканеры и Play Protect помечают самодельные APK с именем известной
платной игры как «возможную подделку». Вероятность таких предупреждений ниже,
если переименовать приложение в собственную игру, например «Кубический мир» или
«Block World». Скажите — переименую (это две строки: `app_name` и
`versionName`) и пересоберу.

## Что делает обёртка

* Отдаёт игру через виртуальный `https://minecraft.local/` — благодаря этому
  `localStorage` работает и прогресс не теряется между запусками.
* При сворачивании приложения странице посылается событие «скрыта» — игра
  сохраняет инвентарь (тот же путь, что и при закрытии вкладки в Chrome).
* Кнопка **«Назад»**: закрывает открытые панели (инвентарь, верстак, печь,
  торговлю, чат, песочницу), иначе выходит из игры.
* Прячет браузерные кнопки («Установить», свой переключатель полного экрана) —
  в приложении они не нужны.
* Полный экран в ландшафте, экран не гаснет, повороты экрана не перезапускают
  приложение.

## Сборка

Автоматически: GitHub Actions → workflow **Build Minecraft APK** (запускается на
push и вручную). APK — в артефактах `minecraft-apk`; для тега `minecraft-v*`
сборка прикладывается к релизу вместе с `SHA256SUMS.txt`.

Локально (нужны JDK 17 и Android SDK 34):

```bash
cd android
gradle assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
gradle assembleRelease      # app/build/outputs/apk/release/app-release.apk
```

Перед сборкой задача `copyGameAsset` копирует `minecraft/Minecraft.html` в
`android/app/src/main/assets/minecraft.html`.

Чтобы выпустить новую версию: замените `minecraft/Minecraft.html`, поднимите
`versionCode`/`versionName` в `android/app/build.gradle` и создайте тег вида
`minecraft-v1.0.2` — релиз с APK соберётся сам.
