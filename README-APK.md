# Minecraft Classic — приложение для Android (APK)

Игра целиком лежит в одном файле `minecraft/Minecraft.html` (≈1,4 МБ) и
работает офлайн. Этот каталог — обёртка, которая превращает её в обычное
приложение Android: иконка в меню, полный экран, сохранение прогресса,
кнопка «Назад» закрывает инвентарь и торговлю.

## Установка без сборки (проще всего)

1. Откройте страницу релизов репозитория → релиз **Minecraft Classic — APK**.
2. Скачайте `app-release.apk` (если телефон откажется ставить — `app-debug.apk`).
3. Откройте файл на телефоне → разрешите установку из неизвестных источников →
   «Установить».
4. Готово: в меню появится «Minecraft Classic». Интернет приложению не нужен.

Проверено на Android 14 (Tecno Pova Neo 3): ландшафтный экран,immersive-полный
экран, прогресс сохраняется.

## Что делает обёртка

* Отдаёт игру через виртуальный `https://minecraft.local/` — благодаря этому
  `localStorage` работает и прогресс не теряется между запусками.
* При сворачивании приложения посылает странице событие «скрыта» — игра
  сохраняет инвентарь (тот же путь, что и при закрытии вкладки в Chrome).
* Кнопка **«Назад»**: закрывает открытые панели (инвентарь, верстак, печь,
  торговлю, чат, песочницу), иначе выходит из игры.
* Прячет браузерные кнопки («Установить», свой переключатель полного экрана) —
  в приложении они не нужны.
* Не имеет разрешения INTERNET и не выпускает переходы наружу.

## Сборка

Автоматически: GitHub Actions → workflow **Build Minecraft APK** → запускается
на push и вручную (**Run workflow**); APK появляется в артефактах
`minecraft-apk`, а для тега `minecraft-v*` прикладывается к релизу.

Локально (нужны JDK 17 и Android SDK 34):

```bash
cd android
gradle assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
gradle assembleRelease      # подписанный: app/build/outputs/apk/release/app-release.apk
```

Перед сборкой задача `copyGameAsset` копирует `minecraft/Minecraft.html` в
`android/app/src/main/assets/minecraft.html`.

Чтобы выпустить новую версию игры: замените `minecraft/Minecraft.html`,
поднимите `versionCode`/`versionName` в `android/app/build.gradle` и создайте
тег вида `minecraft-v1.0.1` — релиз с APK соберётся сам.
