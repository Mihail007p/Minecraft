# NITRO RUSH — Android

Проект-обёртка: игра целиком лежит в `app/src/main/assets/nitrorush.html`
(генерируется скриптом `node tools/build-offline.js --android`).

## Сборка APK локально

```bash
node tools/build-offline.js --android     # собрать offline-версию игры
cd android
gradle assembleDebug                      # нужен JDK 17 и Android SDK 34
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

## Готовый APK без сборки

Откройте страницу релизов репозитория (GitHub → Releases → последний релиз
`NITRO RUSH`) и скачайте оттуда:

* `app-release.apk` — приложение для телефона (подписан, ставится поверх);
* `app-debug.apk` — отладочная сборка, если первая почему-то не ставится;
* `nitro-rush.html` — та же игра одним файлом, открывается в Chrome без установки.

Установка на телефон: скачать APK, разрешить установку из неизвестных
источников, открыть файл. Интернет не нужен — игра работает офлайн.

## Управление на телефоне

Игра автоматически подстраивает HUD под телефон в ландшафте (например,
Tecno Pova Neo 3 — 720×360 css-пикселей): кнопки считаются от высоты экрана
и лежат дугой под большим пальцем, миникарта уходит наверх, чтобы не мешать руке.

* **Руль — «качели».** Зона слева — это одна непрерывная полоса: палец можно
  приложить где угодно и вести влево-вправо, не отпуская (сторона меняется по
  положению пальца, сила — по расстоянию от центра: у края полный ход, ближе к
  середине мягче). Первое касание сразу даёт 45% хода, полный ход доходит за
  ~0,13 с, в центр руль возвращается за ~0,09 с — отклик мгновенный, но без
  дёрганья. Полоса подсвечивается с той стороны, куда вы рулите.
* **Кнопки** в правом нижнем углу, по дуге от большого пальца: нитро — в самом
  углу (её жмут чаще всего), рядом дрифт, левее и чуть выше тормоз/назад, газ
  появляется вместо нитро в углу, если выключить автогаз.
* **Дрифт-переключатель** (в настройках): одно нажатие включает ручник, второе
  выключает. Так одним пальцем можно и дрифтовать, и жать нитро одновременно.
  По умолчанию дрифт держится, пока палец на кнопке.
* **Размер кнопок**: мелкие / обычные / крупные (в настройках).
* **Для левши**: «кнопки слева» — педали переезжают в левый нижний угол, руль
  в правый, HUD зеркалится.
* **Наклон телефона** — альтернативный режим: чувствительность (низкая/средняя/
  высокая) и калибровка в настройках, калибровка автоматически сбрасывается на
  старте заезда, чтобы машину не тянуло вбок.
* **Свайп по экрану** — третий режим: тяните палец влево-вправо в любом месте.
* **Полный экран** включается сам, когда вы нажимаете старт («Старт», событие в
  карьере, «Ещё раз») — вместе с ним игра просит телефон повернуть картинку в
  ландшафт. Вручную — кнопка **⛶** в правом верхнем углу заезда.
* **Вибрация** коротким откликом на нажатия (можно выключить), **экран не гаснет**
  во время заезда, зажатые кнопки отпускаются при паузе.

## Ссылка, которая сразу запускает игру (GitHub Pages)

Обычная raw-ссылка игру не запускает — GitHub отдаёт html как текст (защита от
подмены страниц), поэтому по ней видно код, а не игру. Чтобы ссылка открывала
игру, включите публикацию сайта (один клик, делает владелец репозитория):

1. **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
2. Ветка `arena/01a0b467-minecraft` (или `main`), папка `/ (root)` → **Save**.
3. Через минуту игра доступна по адресу
   `https://mihail007p.github.io/Minecraft/` — открывается сразу, без логина,
   без скачивания и без установки. Любую машину/трассу можно показать другу,
   просто отправив эту ссылку.

Публикация из ветки обновляется автоматически: после каждого push в выбранную
ветку GitHub пересобирает сайт (примерно минута). Никаких workflow для этого
не нужно.

Если в Settings → Pages написано, что для приватного репозитория нужен платный
тариф, вариантов два: сделать репозиторий публичным (Settings → General →
Danger Zone → Change visibility) либо пользоваться ссылкой на релиз
(`nitro-rush.html` или APK) — она работает и без Pages.

## Сборка на GitHub Actions

Workflow «Build NITRO RUSH APK» собирается на каждый push: запускает тесты,
затем `gradle assembleDebug assembleRelease` и публикует результат
(раздел Actions → нужный запуск → Artifacts → `nitro-rush-apk`).
Тег вида `nitro-rush-v*` дополнительно создаёт релиз с APK и html.

Если Actions отключены: Settings → Actions → General → Allow all actions.
